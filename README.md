# Website Van Zoest Vastgoed

Statische site (HTML/CSS, geen build). Live op https://vanzoestvastgoed.nl via Vercel.

- Wijzigen: pas de HTML/CSS aan en push naar `main`; de site wordt daarna opnieuw gepubliceerd.
- Pagina's: Nederlands in de hoofdmap, Engels in `en/`.
- Lettertypen staan in `assets/fonts/` (geen Google Fonts), licht/donker via `assets/thema.js`.
